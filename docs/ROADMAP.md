# GameShelf 路线图

GameShelf 的方向是“本地优先的私人游戏藏书馆”。开发重点不是追赶通用启动器的功能数量，而是把本地收藏、隐私、系列整理和正确启动做深。

## 0.2 稳定性

- 自动备份、手动恢复与恢复前校验
- 崩溃日志和可导出的诊断信息
- 数据库版本迁移与异常退出恢复
- 游戏进程与启动器进程隔离
- 清晰、可操作的错误提示
- 锁定依赖版本并补齐关键回归测试

完成标准：GameShelf 更新或异常退出不会破坏游戏库，也不会影响已经运行的游戏。

## 0.3 游戏库体验

- 批量扫描、结果预览与导入确认
- 重复路径、重复游戏和多版本识别
- 可选择的名称与元数据匹配
- 缺失封面检查与替换流程
- 批量编辑状态、分类、合集与隐私设置
- 封面墙和信息列表两种查看方式

完成标准：新增一批游戏后，用户可以在一个连续流程中完成确认、整理和修正。

## 0.4 自有特色

- Mod 与补丁识别、启用、停用和变更记录
- 存档快照、恢复与多个存档分支
- 角色路线、结局、当前进度和攻略笔记
- 系列合集进度与作品顺序
- 更完整的一键安全视图

完成标准：这些能力围绕私人 GalGame 与本地游戏收藏形成完整工作流，而不是独立的功能入口。

## 1.0 正式发布

- GitHub 自动构建与基础检查
- Windows 安装版和便携版
- 正式版本号、变更记录与更新检查
- 安装、迁移、备份和故障排查文档
- 明确的开源许可证和贡献说明
- 发布前完整回归检查

完成标准：新用户不接触源代码即可安装、使用、更新并安全迁移数据。

## 暂不优先

- 云同步与社交功能
- 游戏商店或下载平台
- 多平台支持
- AI 总结与推荐
- 复杂的插件系统

这些功能只有在核心本地体验稳定后再评估。
