# Package 与存档安全

GameShelf 0.4 管理 GalGame 和普通本地游戏使用的 Mod、汉化/内容/修复补丁目录与存档。R18 始终是内容分级，不是独立游戏类型。

## Mod 与补丁

GameShelf 默认只检测常见 Mod 和补丁目录，并把结果显示在“游戏设置 → Mod 与存档”。检测不会写入游戏目录。

启用或停用只适用于完整目录：

1. UI 显示来源、目标和备份路径。
2. 用户继续后，主进程重新核对状态并显示系统确认框。
3. GameShelf 把目录复制到 `data/package-backups/<game>/<package>/...`，为每个文件记录大小和 SHA-256。
4. 备份成功后，目录在原名称与 `<name>.gameshelf-disabled` 之间做同级重命名。
5. 数据库记录变更前后状态和备份路径。最近一次变更可以按同样流程撤销。

GameShelf 不把补丁文件合并到游戏根目录，不执行第三方安装脚本，也不删除游戏文件。已散装覆盖进游戏目录的补丁不在 0.4 的自动管理范围内。

## 存档快照与分支

用户明确选择一个现有存档目录后，可以创建多个命名分支。分支是快照分组；创建快照不会切换或移动当前存档。

每个快照位于 `data/save-snapshots`，由 `manifest.json` 和 `files` 目录组成。清单记录每个文件的相对路径、大小和 SHA-256；符号链接、特殊文件、越界路径、超过 50000 个文件或 20 GiB 的目录会被拒绝。

恢复流程：

1. 预览时校验目标快照。
2. 系统确认前再次校验。
3. 自动把当前存档保存为“恢复前快照”。
4. 在当前存档同级目录复制并校验恢复内容。
5. 当前目录重命名为 `<name>.gameshelf-restore-old-*`，暂存目录再原子替换为当前目录。
6. 最后一步失败时自动把旧目录改回原名。

恢复成功后不会自动删除 `.gameshelf-restore-old-*`。确认游戏可以读取恢复后的存档，并另行备份后，再由用户手工清理。

## 安全视图

安全视图开启时，隐藏条目不会进入搜索、主页、最近游玩、完成时间线、统计或设置计数。包含隐藏条目的分类上下文和合集也不显示，切换时会清除当前搜索、详情、编辑窗口和旧提示。

安全视图不是加密或访问控制。它不会隐藏磁盘上的游戏、Package、存档、备份或 Windows 最近文件记录。
